# Vision Attend

## AI-Based Face Recognition Attendance System

Vision Attend is a web-based attendance system that uses **Face Recognition** to automatically identify students and mark their attendance.

The project is built using **Python, Flask, OpenCV, DeepFace, HTML, CSS, and JavaScript**.

---

# 📌 Problem Description

Traditional attendance systems require teachers or staff to manually record attendance.

This process can be:

- Time-consuming
- Difficult to maintain
- Prone to human errors
- Difficult to manage for large groups of students
- Dependent on manual record keeping

There is a need for an automated attendance system that can identify students quickly and reduce manual work.

### Problem

> How can we automatically identify a student and mark their attendance using a camera?

### Solution

Vision Attend solves this problem using **AI-based Face Recognition**.

The system captures the student's face using a camera, detects the face, converts it into a numerical representation called a **face embedding**, compares it with registered student faces, and marks attendance when a matching face is found.

---

# 🎯 Project Objective

The main objective of Vision Attend is to automate the attendance process using face recognition.

The system should:

1. Register student face images.
2. Detect faces using the camera.
3. Recognize registered students.
4. Automatically mark recognized students as Present.
5. Display attendance records.
6. Allow attendance records to be downloaded.
